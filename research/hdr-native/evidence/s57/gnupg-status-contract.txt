572: *** DECRYPTION_FAILED
573:     The symmetric decryption failed - one reason could be a wrong
574:     passphrase for a symmetrical encrypted message.
575: 
576: *** DECRYPTION_OKAY
577:     The decryption process succeeded.  This means, that either the
578:     correct secret key has been used or the correct passphrase for a
579:     symmetric encrypted message was given.  The program itself may
580:     return an errorcode because it may not be possible to verify a
581:     signature for some reasons.

583: *** SESSION_KEY <algo>:<hexdigits>
584:     The session key used to decrypt the message.  This message will
585:     only be emitted if the option --show-session-key is used.  The
586:     format is suitable to be passed as value for the option
587:     --override-session-key.  It is not an indication that the
588:     decryption will or has succeeded.
