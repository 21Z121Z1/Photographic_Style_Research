# c/d 独立对照、联合校准与最终 HDR Texture 实测

本轮绑定研究提交 `4438d48`、产品提交 `cf1e790` 加既有研究补丁，run `40855897150`，artifact `12890402452`。同目录保留原始报告与来源。35 项便携回归、105+2 项引擎测试、原生影调与 Texture 重放通过；无关固件参考任务按预定条件跳过。

平均指标取 Tone -0.5/+0.5。仅 c：校准降低 9.64%、留出降低 6.09%；仅 d：校准反而增加 0.59%、留出降低 0.83%；c+d：降低 9.40%/7.29%；联合曝光、增益与 c+d：降低 16.65%/10.11%。这些公开场景已有研究暴露，不是新的未知数据集。

仅 d 令三张图负向 Tone RMSE 分别增加 1.25%、0.36%、1.15%；仅 c 的变化为 -1.13%、+5.42%、+1.41%。所以 d 确有贡献，但不是唯一原因。资源哈希确认单项替换未改变另一张图、曲线、曝光和缩略图。

联合候选提前固定曝光与增益为 0.75 倍，保留默认曝光上限 10.4，并在读取原片资源前重建完整资源。它的三项负向 RMSE 变化为 +0.31%、-8.17%、+0.14%；但 IMG_2604 负向最大误差由 0.0947265625 增至 0.11181640625（+18.04%），留出 IMG_2608 从 0.146484375 增至 0.16064453125（+9.67%）。因此尚不迁入产品，不修改默认值。

所有组的中性 Tone、两端 Color 误差均为零，九份重建文件的原生 SDR/HDR 基图误差均为零。原片亮度组合与完整消费者输入这两个诊断对照，在三张图三个 Tone 点均精确归零；它们不是生成器收益。结论限于当前正向消费者，不能证明完整引擎、反向处理或 Photos 保存重开。

最终编码 HDR 产品完成 12 次 Texture 调用：哑光、眼下提亮和独立平滑各测 SDR/HDR、存储/重算统计。实际 HDR 工作峰值为 2.4135677814483643。SDR 中两种统计输出精确相同，HDR 最大差异分别为 0.07861328125、0.007568359375、0.016845703125。这只证明域的差别会影响像素，不证明 HDR 重算更正确。

Texture 对照是商店模特，采用 1024 边长分析与固定 Studio 调参。真人肤质、全分辨率效果、预设组合、完整反向处理及拍摄时 pre-LTM 数据仍未验证。后续优先绑定实际缩略图解码、曝光/增益与 GTC 采样域，避免重复乘增益或继续增加无像素依据的元数据。
