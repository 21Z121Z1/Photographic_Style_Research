# 固定联合候选的空间影响实测

本轮只测默认生成器与固定联合候选：曝光缩放 0.75、增益缩放 0.75、直方图 c/d，曝光上限仍为 10.4。没有搜索参数，没有新增备选方案，没有修改产品默认值。原片 Styles、蒙版与 EXIF 不进入生成器；参考资源只在生成后读取。

**结论：有整体收益，但副作用不能描述为“只在一张照片的一点点地方发生、变化不超过 1%”。** 1024 边长下，校准平均 Tone RMSE 降低 16.0912%，留出图降低 9.9566%。固定白色显示换算的六组结果中，误差增加超过 1% 的面积为 0.007502%～5.735652%，最大单点误差增加 3.9881%，最大输出变化 6.0357%。负 Tone 的 2600 与 2608 整体 RMSE 分别增加 0.3551% 与 0.3116%，其超过 1% 误差增加的面积较小；2604 的负 Tone 虽然整体改善，局部退步面积却达到 5.735652%。因此不能只看整图 RMSE，也不能只看最大单点。

“局部”还可拆成连续区域：上述白色显示换算中，超过 1% 误差增加的最大单块为 3659 像素，占 1024×768 图的 0.4653%，出现在 2608 的正 Tone。2604 负 Tone 的总退步面积 45107 像素（5.735652%），最大单块 2662 像素（0.3385%）；它是分散多块，而非仅有一个孤立点。包围盒是范围，里面不一定全为变差像素，不能用包围盒面积冒充实际面积。

这支持继续把联合候选作为唯一拟迁入的方案，但尚不以“微小副作用已经满足”将其直接替换产品默认值。本轮完成空间量化，未额外寻找新参数或更改 PR85。是否接受这组实测取舍可以按实际容忍度决定，不要求所有像素零退步。

## 数字的含义

每像素误差定义为与原生参考比较的 RGB 三通道绝对误差最大值；“误差增加”=联合误差−默认误差。“输出变化”=联合输出与默认输出之间的最大通道绝对差，它既可能来自改善，也可能来自退步。两者不能互换。

显示换算中的 1% 是映射后 0～1 编码值的绝对 0.01，不是相对亮度增加 1%，也不是可见差异阈值。线性域的 1% 是 SDR 白色的 0.01。固定白色视图先裁剪至 [0,1]；另一视图先统一除以测得源 HDR 余量再裁剪，并用相同 Display P3 传递函数。它们是诊断视图，不代表 Photos 或真实 HDR 屏幕上的视觉变化。

余量视图的“误差增加 >1%”面积较小（六组均不超过 0.301234%），但不能只选这组数字作为无副作用证明：降低曝光本身会改变数值幅度。固定白色视图中，只有 2600 原生参考的负/正 Tone 分别裁剪 0.376680% / 0.779173% 的通道；其余视图及变体均为 0。两种视图完整列出，不以裁剪掩盖高光。
