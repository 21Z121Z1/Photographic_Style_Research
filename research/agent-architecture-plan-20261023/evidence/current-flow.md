# Current execution ownership

The product app and the research model are separate callers.

`StyleDeltaMapCore.ToolCommandBuilder` turns typed app configurations into `CommandSpec`. `ProcessRunner` passes an argument array to Foundation `Process`. The existing command boundary protects quoted paths without asking each UI view to build shell text. `tools` is already a Python package. Those are structures to preserve, not evidence that every repository module needs a new package.

The reconstruction and inspection commands call `tools.aux_generator`, `tools.inject_style_family`, `tools.semantic_fitter`, and HEIF helpers. The tools generate or inspect HEIF content. They do not certify a recovered Apple image-processing chain. A formal refactor must preserve these public commands and keep source photographs outside public artifacts.

The research `complete_forward.Context` receives raw source textures and ABI buffers. `full_ltm_chain.generate` computes producer and guided-filter values. `main_pre393` consumes those values and supplies the inputs to semantic, skin, color and output helpers. `output_writer` writes the selected result and records written pixels. This is a conditional model with supplied masks, curves and statistics.

`image_chain.run` creates a reviewed function copy from the pinned `complete_forward` source. It changes the SSA404 branch in an explicit experiment and can replace the final code3 numeric backend only under a separate portable option. The default keeps the Darwin arm64 restriction. The `image_chain_cli` command owns context serialization, requests, checkpoint files, parameter comparisons, source hashes and exit status. `context_color_api` separately owns admission to frozen precision catalogs. `bound_validation` and `validate_portable` separately capture scientific-command source and evidence hashes.

These boundaries have different purposes. A frozen source catalog is a historical scientific identity, not a cache to regenerate during package migration. A new shared runner must parse existing formats into a new request type, retain the original identity, and report the unsupported capability. It cannot rewrite a manifest hash so a moved file looks like the old measured source.

Current references are pinned to `611ac4f6fe525ad3ba80ba5025aa8b5f0a45a079`. The newer implementation branch adds `module_sensitivity` after that commit. Its entry is included in the migration inventory by reading the later commit, while the prototype execution baseline remains the pinned worktree.
