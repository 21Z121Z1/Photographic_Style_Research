# S28：明确人工观测误差合同下的候选稳健性

复用两个已有 v3 目录，在写出的 RGB 上引入至多正负一个 half ULP 的人工观测误差。预先固定的 **576 个单分量扰动全部使精确候选为空，容差匹配全部保留真实控制**。第一场景有 4 个扰动扩大了候选，第二场景没有扩大；联合容差观测可排除这些新增候选，但结果仍等于更强的第二场景，额外消除数为 0。原有平台碰撞继续存在，没有唯一反求结论。

本轮全部结果为 **model_only**，已知源图及完整辅助 context。新增模型前向、原 kernel 和编译均为 0。人工容差不是 JPEG、HEIC、GPU 或真实照片测量误差模型；原精确验收阈值、算术精度和舍入预算均未改。

## 冻结合同、身份与规则

合同 `evidence/observation-error-contract-s28a.json` 的 SHA256 为 `8a6269e1571434b96ad6a7b6c08f44e985268b4ae42c58cdc0e5f5c7b321852a`，实验计划 SHA 为 `be16b082421b5edcdcf970526c1cc88c22f8b67421a153b5769077e60ea9b5b6`。两者在生成任何扰动及匹配扫描之前写入；实验运行前绑定再次核对其 SHA。

每帧输出是 5×6 RGBA，原 3×4 source 写入偏移 (1,1)。允许容差的分量是这 12 像素的 **36 个 RGB**；其余 **84 个分量逐位精确**，包括已写 alpha 和全部未写存储。全部 146 状态预检确认 written RGB 正且有限、alpha 为 half1、未写区保持初始值。第一场景 written RGB 范围约 .443115.. .578125，第二约 .068970.. .907715。

距离使用有限 binary16 编码的有符号全序 rank，正数区就是相邻 half 的 ULP 步数。合同明确 -0/+0 为相邻不同编码；本数据的 written RGB 严格正，不涉及该歧义。非有限值、越过有限 rank 的步进拒绝，不截断或饱和。

身份仍为 iPhone17,3 / iOS27.0.1 / build24A446 / SmartStyleV1 / CMISmartStyleProcessorV1；ABI version0 不是 HEIC metadata 版本。v3 SHA `9358741644914631950a72161b25967ba9c433400d1faf3dbb4267db1fb036da`，其 243 份模型源、单场景 API、两个目录及旧证据均未改变。只反求内部 `post-scene SSRParams.color field3 byte12 raw f32`，域仍是 canonical +0..3/8（raw `0x00000000..0x3ec00000`），cast0/tuning2，其余输入固定；没有 UI 映射或新增自由参数。

预先选择原 state0、7、17、122：分别为 raw0、state7 原代表值、已有目标 .125、.34375。扰动函数只读取 writer 数组与固定坐标规则，不读取真实控制或匹配结果：

- 合法主规则：最前 written RGB 分量 +1 / -1 ULP；全部 written RGB 按 `(y+x+c)` 奇偶棋盘式 ±1 ULP；以及不扰动基线。
- 合同外负例：最前 written RGB +2 ULP、最前已写 alpha +1 步、最前未写 RGB +1 步。
- 单分量枚举：每个目标、每个 scene、全部 36 个坐标及 [-1,+1]，共 576 个；固定顺序先于扫描结果。

`Catalog.scan` 对全部 146 状态检查全部 120 个分量，返回所有满足约束的 raw f32 区间并集、端点开闭、人口、逐状态诊断和 bitmap。已知匹配与 unknown 可能区域分开。当前两个完整目录的 unknown 数为 0；临时删除/unknown 行测试仍保留可能区。联合观测须明确声明同一 raw field3；实验先验证两目录的 build/v3/域/字段/partition 合同一致，再求区间交集，不最近值兜底。

人口单位是原始 f32 位型数，不是接口状态数。8 个预定联合规则对每个目标均分别检查精确和容差，包含一帧精确、另一帧扰动的情况。某单帧精确候选已空时，精确联合仍为空，不能由另一帧救回。合同外 24 个单帧负例的容差候选也全部为空；对应联合负例同样失败。这只排除本模型域和合同内的共同参数，不判某张目标非法。

全部单分量 ±1 枚举中，第一 scene 每个目标只有 1/72 个扰动扩大候选，第二 scene 每个目标 0/72。下表给出全部四个扩大见证及与第二 scene **未扰动合法基线**相交的结果；这些是已冻结枚举的事后诊断，不是重新选择扰动规则。

## 最小失败、不可区分参数与误差盒

最小失败是平台目标、第一 scene `[1,1,R]` 从 half 编码 **14329 → 14328**：只改 1 个分量、1 个 ULP，原精确非空变为空，容差仍有 1018499073 个候选。以预定非零扰动目标 `lex(L0分量数,L∞步数)` 衡量，它达到离散下界 (1,1)，故是该目标下全局最小；没有宣称感知距离最小。

具体不可区分参数是 raw `0x00000000` 与 `0x3c23d70a`，即 0 与 f32(.01)=.009999999776482582：两 scene 的 writer 全部 120 个 half 逐位相同。它们即使没有人工误差也不能区分；平台区间仍为 `[0,.02210235595703125]`，1018499073 个 f32。

还有单 scene 的误差诱发歧义，例如第一 scene 平台 `[3,3,B] -1` 的同一观测同时兼容 state0 的 raw0 与 state2 代表 raw `0x3cb52000`（.0221099853515625），原精确输出不同；第二 scene 的平台观测排除 state2。完整并集和其余三个具体参数对保存在摘要 JSON。

另外穷尽检查 10585 个不同 state 对。两个半径1观测盒重叠要求每个 RGB 预测差至多 **2** 步且精确区相同，与“预测中心直接相容”的 ≤1 不同：

|关系|第一 scene 对数|第二 scene 对数|双 scene 对数|
|---|---:|---:|---:|
|中心直接满足 ±1|24|1|见完整结果|
|两个半径1观测盒可重叠|877|1|1（仅0/1）|

双 scene 未发现新的非精确重叠对，故没有伪造“误差新增联合参数对”的成功见证。原 0/1 仍碰撞，同一 state 内也仍含大量 raw 值。盒重叠关系不保证传递，不能把它压成新的等价类；结论仅覆盖这两个冻结模型目录和本人工合同。

## 验证、成本与证据

19 项定向测试通过（unittest .843 秒），覆盖全部有限 half 编码往返、signed zero、有限边界、120 分量约束、合同外负例、错误 context/shape/合同、显式共享、unknown/缺行可能区，以及禁用模型前向和原 kernel 入口后的查询。独立审计在正 half 编码上直接比较保存的 632 个观测和全部 state 对，复核 bitmap、完整区间及人口；不借用 rank/scan 的约束判断。

实验核心为 56 个主扫描 +576 个单分量扫描，共 **632 次目录扫描、92272 个 state-observation 检查、11072640 个分量约束**，7.382 秒。这不是独立照片数。另有 56 次旧精确 API 参考查询和 10585 个 state 对诊断，不混入核心扫描计数。独立审计另重放 632 个保存数组约束、10585 对及 4 个区间交集；测试亦仅做数组/区间查询。所有这些都没有新增前向、固件调用或编译。

首次测试中 1 个断言误将区间说明文字与附加 `signature_ids` 当成数学结果比较；实际 raw 范围及端点一致。只修测试为 `Interval` 比较后 19 项通过，没有改实验/数值源码或结果。失败 pre/post 原件、测试源码与原日志保留在任务私有 `s28-private-source/`；Git 提交其 SHA 和仅替换绝对路径的失败日志，详见 `source-iteration-s28c.json`。失败没有抹除或记成通过。
