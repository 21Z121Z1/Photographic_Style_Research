# macOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native macOS SwiftUI app for the existing Photographic Style Research tooling, without a separate visual companion, and make it build/run/test from this repository.

**Architecture:** Add a SwiftPM GUI app target named `StyleDeltaMap` and a non-UI library target named `StyleDeltaMapCore` at the repository root. Keep HEIF mutation in the already validated Python tools; the macOS app is an operator shell that builds safe `Process` commands, captures logs, and presents direct injection, gain-map/RAW reconstruction, and validation workflows. Use a single project-local `script/build_and_run.sh` to build, stage an `.app` bundle, launch it, and expose the Codex Run action.

**Tech Stack:** SwiftPM, Swift 6, macOS 14+, SwiftUI `WindowGroup`/`Settings`/`NavigationSplitView`, Observation, Foundation `Process`, existing Python tools, XCTest.

---

## Current Sources And Best-Practice Inputs

- Apple SwiftUI App and Scene documentation: use `App`, `WindowGroup`, and scenes for app structure.
- Apple `NavigationSplitView` documentation: use a sidebar-detail split for macOS operator workflows.
- Apple `Settings` documentation: expose settings through a real macOS settings scene.
- Apple `fileImporter` documentation: security-scoped file URLs matter when importing user-selected files; this first app keeps path selection local and non-sandboxed, but command execution code treats paths as data, not shell strings.
- Swift Package Manager documentation: define an executable product and targets in `Package.swift`.
- Build macOS Apps plugin guidance: add `script/build_and_run.sh` and `.codex/environments/environment.toml`; stage SwiftPM GUI apps into `dist/<AppName>.app` before launch.

## File Structure

- Create `Package.swift`: SwiftPM package with executable product `StyleDeltaMap`, library target `StyleDeltaMapCore`, and test target.
- Create `Sources/StyleDeltaMap/App/StyleDeltaMapApp.swift`: app entry point, regular activation, scenes, commands.
- Create `Sources/StyleDeltaMapCore/Models/*.swift`: workflow enum, path configuration structs, run result models.
- Create `Sources/StyleDeltaMap/Stores/AppStore.swift`: app state and workflow actions using Observation.
- Create `Sources/StyleDeltaMapCore/Services/*.swift`: repository locator, command builder, process runner, default paths.
- Create `Sources/StyleDeltaMap/Services/*.swift`: AppKit file picker, reveal, and open helpers.
- Create `Sources/StyleDeltaMap/Views/*.swift`: sidebar, direct injection form, gain-map reconstruction form, validation form, run console, settings view, reusable rows.
- Create `tests/StyleDeltaMapTests/*.swift`: tests for command construction, repository discovery, and process-runner behavior that do not require a GUI.
- Create `script/build_and_run.sh`: plugin-standard build/run/verify/log/telemetry script.
- Create `.codex/environments/environment.toml`: Codex Run action.
- Create `docs/macos_app_2026-05-31.md`: user-facing app notes and verification evidence.
