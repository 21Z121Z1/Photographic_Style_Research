# Photographic Style Research verification map

Use a fresh evidence directory for every journey. Run doctor first. The portable CLI can run in this Linux workspace without photographs. Native, HEIF and app journeys require their own materials or host and are not covered by portable success.

## Features

- [Synthetic parameter outputs](synthetic-parameters.md) verifies source-to-writer artifacts and aligned parameter effects.
- [Bright selection and negative domains](bright-and-fallbacks.md) verifies the explicit selected branch, missing masks, and unknown propagation.
- [Native pow preflight](native-pow.md) records the real material and host gate without substituting a backend.
- [HEIF structural reports](heif-structure.md) describes the actual structure inspection commands and required authorized input.
- [macOS validation app](macos-app.md) describes the UI path and the native proof that remains unavailable in Linux.

## Evidence standards

Store commands, terminal output, exit codes, source identity, inputs and persisted outputs together. A blocked or skipped journey remains blocked or skipped. A report field alone does not prove output files exist. Reopen those files and inspect their values. Retain all proof artifacts during cleanup.
